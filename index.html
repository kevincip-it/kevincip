About Me

Passionate about driving innovation through code.

Halo, perkenalkan saya Kevin. Saya adalah seorang mahasiswa Teknik Informatika di Politeknik Negeri Samarinda. Bagi saya, teknologi bukan sekadar barisan kode, melainkan alat untuk memecahkan masalah nyata. Ketertarikan utama saya berada di persimpangan antara pengembangan perangkat lunak (software development), analisis data, dan eksplorasi Kecerdasan Buatan (Artificial Intelligence).

Dalam keseharian, saya banyak menghabiskan waktu bereksperimen dengan Python, SQL, dan merancang antarmuka menggunakan Android Studio maupun Visual Studio Code. Saya juga terbiasa mengelola basis data dengan MySQL serta melakukan analisis spasial menggunakan QGIS.

Di sini, Anda akan menemukan hasil karya profesional saya sekaligus tulisan-tulisan santai mengenai hal-hal yang sedang saya pelajari dan baca. Selamat membaca dan mengeksplorasi!
